## 数据与运行环境

迁移按功能拆分为 `20261007_100000` 至 `20261007_190000`；同步 schema 说明、
自托管来源清单和空库基线。已有栈仅应用哈希匹配的增量，保留账号与持久卷。
应用通过 authenticated 系统管理员会话调用后台服务，因此新增表与 RPC 不依赖
service_role key；私有 Storage 桶由迁移安装管理员限定策略，普通用户通过受归属
校验的附件 API 读取。新上传和早报生成可分别由环境变量关闭。

更新后主动刷新 PostgREST 的 schema 缓存，覆盖已运行 REST 容器的新增列。
镜像包含附件接口需要的 Sharp 原生依赖，并在最终 runner 中执行实际图片处理。
本地更新会重新启动挂载脚本的独立 scheduler，确保五分钟轮询立即加载；
工作区关闭后的焦点返回会保留用户已移到输入框的新焦点。
文件追踪使用 [Next 的运行文件包含配置](https://nextjs.org/docs/app/api-reference/config/next-config-js/output)，
原生文件随当前平台依赖安装，参见 [Sharp 安装说明](https://sharp.pixelplumbing.com/install/)。

数据库、Storage 和私有栈配置备份保留在本机 `.taibu-local/backups/`，不提交到仓库。
本轮不执行线上迁移、Git 提交或推送。
